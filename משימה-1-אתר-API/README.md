## ✅ מה נבנה: "האם להשקות היום?" (רעיון 1)
**קישור:** https://hagit2303.github.io/intel-hishtalmut/api/ · הקוד: [index.html](index.html)

- בוחרים חלקה (הכפר הירוק, חיפה, באר שבע, קריית שמונה, אילת) או "המיקום שלי".
- האתר מבקש מ-Open-Meteo גשם ואידוי-דיות (ET₀) לשלושה ימים אחורה, היום ושלושה ימים קדימה.
- **המלצה:** צפוי גשם של 5 מ״מ ומעלה ביומיים הקרובים ← לא להשקות. אחרת, גירעון מים (ET₀ פחות גשם) של 10 מ״מ ומעלה ← להשקות. פחות מזה ← אפשר לחכות.
- תרשים: גשם (כחול, מים נכנסים) מול אידוי-דיות (אדום, מים יוצאים).
- בלי מפתח ובלי הרשמה. אם השירות לא עונה מופיעה הודעה וכפתור "נסו שוב".
- נבדק בדפדפן: נתונים חיים נטענים, החלפת חלקה עובדת, בלי שגיאות, מתאים לרוחב טלפון.

**מה אפשר להוסיף בהמשך:** מקדם גידול (Kc) לפי סוג הגידול, סוג קרקע, וחיבור לנתוני חיישן לחות אמיתי בחלקה.
