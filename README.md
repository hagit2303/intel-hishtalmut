## מה זה API, במשפט
API הוא "דלת" מסודרת שדרכה האתר מבקש מידע משירות אחר ומקבל תשובה.
דוגמה מהמפגש: האתר שואל שירות של נתוני רעידות אדמה, מקבל רשימה, ומציג אותה על מפה.
יש שירותים חינמיים בלי מפתח (הכי פשוט), חינמיים עם מפתח, ובתשלום.
**מפתח סודי לא נכנס לאתר:** כל מי שפותח את האתר יכול לראות אותו.
